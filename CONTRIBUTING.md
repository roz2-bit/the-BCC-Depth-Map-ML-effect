# Contributing

Thanks for helping improve DepthCraft Workflow Kit.

## Scope

Contributions should improve repeatability, accessibility, documentation, or dependency-light tooling. Do not submit proprietary vendor binaries, installers, effect presets, stock footage, fonts, or project files that require licensed applications to open.

## Workflow

1. Create a branch from `main`.
2. Make a focused change and update related documentation.
3. Use relative links and label all values as examples where they are not universal.
4. Run `python -m unittest discover -s tests -v` and `python tools/validate_repo.py`.
5. Open a pull request using the repository template.

Use the issue templates for bugs and workflow improvements. Include the operating system, relevant application versions, and a minimal reproduction without uploading proprietary media.
