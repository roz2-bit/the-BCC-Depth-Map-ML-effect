# Repeatable checklist

## Before editing

- [ ] Licensed source media and fonts are available.
- [ ] AE, BCC+, and CapCut versions are recorded.
- [ ] Frame rate, resolution, aspect ratio, and color intent are agreed.
- [ ] `metadata.json` is copied from the example and completed.

## During the depth pass

- [ ] Clean source layer is retained.
- [ ] Depth result is tested on a representative range.
- [ ] Difficult edges and manual masks are noted.
- [ ] Shot and comp names follow the naming convention.

## Before handoff

- [ ] Master is reviewed at 100% and delivery size.
- [ ] Color and audio settings are documented.
- [ ] CapCut project has a clean pre-platform version.
- [ ] Review and final exports are clearly separated.
- [ ] No proprietary files were added to this repository.
- [ ] `python tools/validate_repo.py` passes.
