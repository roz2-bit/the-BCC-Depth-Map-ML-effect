# Naming conventions

Use stable identifiers so a team can find a shot without opening an application project.

```text
PROJECT_SC###_SHOT###_<role>_v###
```

Examples:

```text
DC01_SC010_SHOT020_source_v001
DC01_SC010_SHOT020_depth_v003
DC01_SC010_SHOT020_master_v003
DC01_SC010_SHOT020_capcut_9x16_v002
```

Use lowercase file extensions, three-digit scene/shot numbers, and increment versions rather than overwriting approved renders. Keep platform suffixes explicit: `16x9`, `9x16`, or `1x1`.
