# CapCut finishing and export

Import the rendered AE master into a CapCut project whose canvas, frame rate, and aspect ratio match the delivery plan. Keep the AE master untouched and apply editorial changes above it.

## Finishing pass

- Trim and retime only after confirming the master frame rate.
- Add captions and graphics in named tracks.
- Check safe areas for each platform version.
- Disable automatic enhancement, HDR conversion, or sharpening unless the delivery spec calls for it.
- Keep a clean timeline version before platform-specific changes.

Create one CapCut project per deliverable family or use clearly labeled duplicate versions. CapCut project files are application-specific and may not be portable; keep them in private project storage, not this repository.

## Export

Use the platform's current technical requirements, then record the actual export settings in the handoff log. Export a review copy separately from the final master so a low-bitrate preview is never mistaken for the delivery file.
